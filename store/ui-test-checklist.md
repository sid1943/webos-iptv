# Optimize — UI Test Checklist

Run on:
- LG webOS TV (target model/version)
- Remote control

Checklist
- App launches without crash.
- Empty state appears when no playlists are configured.
- Settings opens with Blue button.
- Add playlist flow works with on-screen keyboard.
- Channel list opens with OK/Enter.
- Up/Down zaps channels.
- Red toggles favorites.
- Yellow shows channel info.
- Green opens EPG (if EPG data exists).
- Back returns to previous channel, then exits.
- Stream error shows a toast and recovers.
- After 30 minutes of playback, app remains responsive.
